# BidBuy Renewal HTML

BidBuy 리뉴얼 HTML 산출물 정리 문서입니다.  
각 HTML 파일이 어떤 화면인지 빠르게 확인할 수 있도록 PC, Mobile 기준으로 페이지명을 정리했습니다.

## Folder

| 폴더 | 설명 |
| --- | --- |
| `web/` | PC 웹 화면 |
| `mobile/` | 모바일 웹 화면 |
| `images/` | 공통 이미지 리소스 |

## 작성 기준

- 파일명은 실제 HTML 경로 기준으로 작성합니다.
- 페이지명은 HTML `<title>`과 화면 목적을 기준으로 정리합니다.
- 중복 파일은 가능하면 언더스코어(`_`)가 있는 파일명을 기준으로 관리합니다.
- 파일을 추가하거나 이름을 바꾸면 이 문서의 표도 같이 업데이트합니다.
